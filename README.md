# One Sentence for a Traveler from 1800

One sentence explaining the modern internet to someone arriving from 1800,
written for the [Make.fun bounty](https://make.fun/bounty/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb).
It builds only from things a person from 1800 already knows — a library, a
post office, a letter, ink — so the picture lands without a single word coined
after their time.

`main.py` writes the sentence to `/output/entry.txt`:

> Imagine every library on earth joined into one, with a post office inside it that delivers any letter to the far side of the world before the ink dries.

Run it with `python3 main.py`.
